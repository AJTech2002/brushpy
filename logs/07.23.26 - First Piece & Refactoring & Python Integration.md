**`Engine`** now owns the single `MTL::CommandQueue` and exposes a nesting-aware command buffer API: `beginCommandBuffer()` / `endCommandBuffer(waitUntilCompleted)`. Nested calls share the active buffer (only the outermost, unmatched call actually commits/waits) — that's what lets the same code run either standalone or inside a larger pass without either side knowing about the other.

**`Canvas`** now owns its own `_outputTexture` (created in `init()`) and no longer references `Renderer` at all — `Canvas::render()` brackets its own compositing pass with `Engine::beginCommandBuffer`/`endCommandBuffer`, so it can run fully headlessly.

**`Layer::draw()`** brackets each primitive's rasterization the same way, so a primitive can be drawn standalone (e.g. directly from Python bindings) without a `Canvas` or `Renderer` in the picture.

**`Compute::setup()`** reads `Engine::activeCommandBuffer()` instead of `Renderer::activeCommandBuffer()` — it never begins/ends the buffer itself, just joins whatever pass is already active (matching the original design where multiple dispatches share one buffer).

**`Renderer`** dropped its own `_renderQueue`, `_activeCommandBuffer`, and `_outputTexture`; presentation now reads `_canvas->outputTexture()` as the blit source and uses `Engine::beginCommandBuffer`/`endCommandBuffer` for its own on-screen pass, so a full frame (artwork build → layer rasterization → canvas composite → present) still shares one command buffer when driven through `Renderer::draw()`, exactly as before, but each layer no longer requires a `Renderer` to exist.

Both `BrushPY` and the `bpy` Python module build clean with no new warnings. Next natural step would be exposing `Canvas::outputTexture()` (or a pixel-readback helper) through `bindings.cpp` if the goal is to pull rendered results back into Python/numpy headlessly.

import time

from pyglm import glm

canvas.add_layer(layer)


while True:

        # random color

        square = bpy.Square(glm.vec2(10*(100-i), 10*(100-i)), glm.vec4(col[0], col[1], col[2], 1.0))

        layer.draw(square)

        layer.draw(image, mat)
        canvas.render_out("/Users/ajayvenkat/Development/metal-procedural-art/artworks/test.png")
        time.sleep(0.01)
