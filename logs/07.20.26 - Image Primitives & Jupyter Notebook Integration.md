Added Image Primitive support.

- Layers are like storage textures, output locations which can be ordered by sort on the canvas 
- Primitives are like brushes, they generate something on a Layer
- Layers can be visibility toggled + blending changed + opacity changed

So an artwork can be worked on over multiple sessions and it prefers the Jupyter notebook style, then Layers become like temp storage textures. Creatively as well it makes sense that you add as you go and this would be the preferred workflow, and in future brush strokes etc can be auto triggered python commands - the live Brushstroke visualiser will have to be handled custom.
