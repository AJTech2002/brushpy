## Notes

- Layer is a `Primitive` and can be added to other `Layer` objects
- Canvas contains a list of `Layers` which it composites using the `Layer` final output image
	- `draw` function should only re-trigger a draw on the tiles that were affected

- `Renderer` : Stores the current state, exposes things via Singleton
	- `Renderer::writeToTexture(MTL::Texture, region)` - Queues into via Command Buffer
	- `Renderer::currentCommandBuffer` - Works for any function called within draw, this can be unbound after the draw region so that we can error this out
	- `Canvas` : Stores a list of layers, tracks dirty regions, triggers re-draw for affected regions, communicates with the Renderer
		- `Layer` : Stores the current pixel data for the layer, stores list of `Primitive`s , is a `Primitive` itself and can draw out to a certain `BTexture`, ability to *add* sublayers/primitives
			- `Primitive` : This is where specific rendering logic lives and this just contains the logic to figure out how to draw this to the screen
				- Deciding not to cache the primitive in a Texture and rather re-compute every time to allow parameter changes in runtime layer independently
				- Contains `computeShader`, bindings, blending fn when this is added in 

- `BTexture` : Wrapper for Metal Texture, can write to a certain region using a selected compute shader 

## Design Questions

- At what layer should the tilling engine live
	- Should it only exist at the canvas level, and what about the textures should there even be a layer texture, should the layer texture be tiled or the canvas texture
- How can we ensure that the least amount of draw calls are performed when something changes 
- How should command processing be done, queueing etc. 

### Command Flow

- Canvas figures out dirty regions (initially can just call on the whole screen before Tiling is implemented)
- Tells layers to re-draw
- Layers re-generate primitives that are dirty and blit them onto their own texture by region
- Canvas composites all layers together with their blending function

To try to get a basic set of images rendering to the main canvas through the layer system, render a few different images with different transforms, stacking, various opacities.
